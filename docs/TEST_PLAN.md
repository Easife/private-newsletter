# 首次测试计划

当前版本已于 2026-09-27 完成一次 OpenCode 免费模型 CLI 端到端运行，fetch 至 publish 七个阶段全部成功。以下清单保留为后续回归和故障注入计划。

1. 静态检查：Python 编译、导入、配置解析、PowerShell 语法检查。
2. 单元检查：稳定 ID、时区日期、去重边界、AI ID 校验、HTML 转义、原子写入和恢复拒绝条件。
3. 环境诊断：依赖、代理、15 个来源连通性、OpenCode 健康检查、CLI 凭据和默认模型可用性；不能假设桌面端登录自动共享给 CLI。
4. 小样本集成：固定本地 RSS 样本，不访问真实新闻源；模拟 OpenCode 响应。
5. 真实手动运行：指定当天日期，核对来源状态、排名、翻译、成员关联和输出页面。
6. 故障注入：在排名、翻译、渲染阶段分别中断，确认 `current.json` 不变，并验证 `--resume`。
7. 计划任务演练：手动触发 Windows Task Scheduler，核对隐藏服务、日志、退出码和重复实例保护。

验收重点：无 WSL 进程、无需打开 OpenCode UI、不存在索引错配、日期不回退、配置修改后不复用旧缓存、失败不发布半成品。

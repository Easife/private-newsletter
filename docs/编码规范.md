# 编码规范

## 统一编码：UTF-8

本项目所有文件统一使用 **UTF-8** 编码。

---

## 1. 文件类型要求

| 文件类型 | 编码 | 说明 |
|---------|------|------|
| Python (`.py`) | UTF-8 | 源代码 |
| YAML (`.yaml`) | UTF-8 | 配置文件 |
| JSON (`.json`) | UTF-8 | 数据文件 |
| Markdown (`.md`) | UTF-8 | 文档 |
| HTML (`.html`) | UTF-8 | 网页输出 |
| CSS (`.css`) | UTF-8 | 样式文件 |

## 2. Windows 环境注意事项

### 2.1 控制台编码

Windows 中文环境默认使用 GBK (cp936) 编码，导致中文日志乱码。

**乱码表现：**

```
[DW] ��ȡ 135 ������
[INFO] ��Դ״̬: �ɹ� 9/17, ʧ�� 8/17
[INFO] �ܼƻ�ȡ 343 ������
```

**修复方法：**

在 `run.py` 顶部添加：

```python
if sys.platform == "win32":
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")
    sys.stderr.reconfigure(encoding="utf-8", errors="replace")
```

### 2.2 PowerShell 编码

```powershell
# 设置控制台编码为 UTF-8
chcp 65001

# 或在 PowerShell Profile 中永久设置
notepad $PROFILE
# 添加: [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

### 2.3 文件保存

- 编辑器（VS Code、Notepad++）保存文件时选择 UTF-8 编码
- VS Code 右下角可查看/切换文件编码

## 3. 如何避免中文日志乱码

### 3.1 原则

- 所有 `print()`、`logging.info()` 中的中文都应使用 UTF-8
- 不要用 `encode('gbk')` 或 `encode('cp936')`
- Windows 入口脚本必须添加 `reconfigure(encoding="utf-8")`

### 3.2 日志配置

```python
# 正确：使用默认编码（reconfigure 后为 UTF-8）
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)

# 错误：指定编码为 GBK
handler = logging.StreamHandler(open(sys.stderr.fileno(), 'w', encoding='gbk'))
```

### 3.3 JSON 读写

```python
# 正确
with open("data.json", encoding="utf-8") as f:
    data = json.load(f)

# 错误（Windows 默认 GBK）
with open("data.json") as f:
    data = json.load(f)
```

## 4. 常见乱码表现

| 乱码 | 原因 |
|------|------|
| `��ȡ` | UTF-8 字节被 GBK 解码 |
| `ʧ��` | UTF-8 字节被 GBK 解码 |
| `����` | UTF-8 字节被 GBK 解码 |
| `锟斤拷` | GBK 编码被 UTF-8 解码后再 GBK 解码 |
| `烫烫烫` | 未初始化内存的 GBK 编码 |

## 5. 排查方法

### 5.1 检查 Python 编码

```python
import sys
print("stdout:", sys.stdout.encoding)
print("stderr:", sys.stderr.encoding)
print("default:", sys.getdefaultencoding())
```

正常输出应为：
```
stdout: utf-8
stderr: utf-8
default: utf-8
```

### 5.2 检查文件编码

```bash
file script.py        # 应显示 "UTF-8 text"
file config.yaml      # 应显示 "UTF-8 text"
```

### 5.3 测试中文输出

```python
import sys
if sys.platform == "win32":
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")
print("测试中文：获取 135 条新闻")
```
